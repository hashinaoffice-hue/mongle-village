# 몽글 마을 (멀티플레이)

채널을 골라 들어가면 같은 채널 사람들과 들판과 숲, 폭포 뒤 동굴, 별빛 언덕, 해변을 함께 산책할 수 있는 3D 맵이에요.
처음 들어올 때 닉네임을 정해요 (비워 두면 랜덤). 닉네임은 그 접속 동안만 쓰고, 새로고침하면 다시 정해요.
같은 채널에 같은 닉네임이 있으면 다른 이름을 골라야 해요. 서버에 저장하는 데이터는 없어요.

## 실행

`start.bat`을 더블클릭하세요. 처음 한 번은 필요한 파일을 설치해요.
직접 실행하려면:

```
npm install
npm start
```

켜지면 접속 주소가 표시돼요.

- 이 PC: http://localhost:8787
- 같은 와이파이의 다른 기기: http://(표시된 IP):8787

## 인터넷에 배포 (Render)

1. 이 폴더를 GitHub 저장소에 올려요.
2. [Render](https://render.com)에서 **New → Blueprint**를 누르고 저장소를 고르면 `render.yaml` 설정대로 서버가 만들어져요.
3. 배포가 끝나면 `https://(서비스 이름).onrender.com` 주소로 누구나 접속할 수 있어요.

무료 요금제는 15분 동안 아무도 없으면 잠들어서, 그다음 첫 접속은 30초~1분 정도 걸려요.

## 설정

| 환경 변수 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | 8787 | 서버 포트 |
| `MAX_PER_CHANNEL` | 20 | 채널당 최대 인원 (채널은 10개) |
| `UFO_CHANCE` | 0.1 | 유성우가 내릴 때 생기는 깜짝 이벤트 확률 (0~1) |

## 하늘과 시간

하늘은 지금 시각(한국 위도·경도 기준)에 맞춰 새벽·아침·낮·노을·밤으로 바뀌어요.
채널마다 1시간씩 늦어요. 1채널이 지금 시각이고, 2채널은 1시간 전, 10채널은 9시간 전이에요.
채널을 고를 때 버튼의 작은 동그라미로 그 채널이 낮인지 밤인지 볼 수 있어요.
다른 시간대를 미리 보려면 주소 뒤에 붙이세요.

- `?t=19.5` : 오늘 19시 30분으로 고정 (1채널 기준, 다른 채널은 여기서 1시간씩 늦어요)
- `?t=5&speed=600` : 새벽 5시부터 600배 빠르게 흐름

## 날씨

채널마다 따로 비나 눈이 와요. 한번 시작하면 4시간 이어져요.

- 비: 가랑비로 시작해 점점 세차게 내리고, 가장 세찰 때는 천둥번개가 쳐요.
- 눈: 오래 내릴수록 마을 곳곳에 쌓이고, 끝나 갈 무렵 눈이 그치면서 녹아요. 많이 쌓이면 걸을 때 사박사박 소리가 나요.
- 날씨에 따라 동물 친구들이 하는 말도 달라져요.
- 채널 고르는 화면에서 버튼의 '비', '천둥', '눈' 표시로 그 채널 날씨를 볼 수 있어요.

날씨는 시각과 채널 번호로만 정해져서(6시간마다 절반 조금 넘는 확률로 한 번) 서버에 저장하는 것이 없고, 같은 채널 사람은 같은 날씨를 봐요.
미리 보려면 주소 뒤에 붙이세요: `?w=rain&wp=0.7` (종류 `rain`/`snow`, 4시간 중 얼마나 지났는지 0~1)

## 몽글 해변과 등대

마을 남쪽 문을 나서서 잔디 언덕길을 내려가면 모래사장과 바다가 나와요.

- 바다는 무릎 깊이까지 걸어 들어갈 수 있어요. 걸으면 첨벙첨벙 소리가 나요.
- 파라솔 아래 의자에 앉아 바다를 볼 수 있어요.
- 나무 부두를 따라가면 등대 섬이 나와요. 등대 문 앞에서 전망대로 올라갈 수 있어요.
- 밤이 되거나 비가 세차게 오면 등대 불빛이 빙글빙글 돌아요.
- 해변에도 별사탕이 3개 숨어 있어요 (모래성, 부두, 등대 전망대).

## 반딧불 동굴

오두막 숲의 무지개 폭포, 물줄기 바로 뒤 절벽에 숨은 입구가 있어요. 연못 가장자리를 돌아 물줄기 뒤로 가면 들어갈 수 있어요.

- 동굴 안은 바깥 시간과 날씨에 상관없이 늘 어스름하고, 빛나는 버섯과 수정, 반딧불이 길을 밝혀요.
- 빛나는 연못은 얕아서 걸어 들어갈 수 있어요. 가운데 작은 섬이 있어요.
- 천장을 올려다보면 반딧불이 별처럼 박혀 있어요.
- 서쪽 굴 끝 수정 방에는 폭신한 분홍 버섯이 있어요. 밟으면 높이 튀어 올라 수정 선반에 닿을 수 있어요.
- 연못가 바위에 앉아 쉴 수 있어요.
- 동굴에도 별사탕이 2개 있어요 (연못 섬, 수정 선반).
- 꼬마 박쥐 초롱이 종유석에 거꾸로 매달려 있어요.

## 별빛 언덕과 천문대

마을 광장에서 동쪽 이정표를 따라 오솔길을 오르면 언덕 꼭대기에 천문대가 있어요.

- 망원경 앞 의자에 앉으면 망원경으로 하늘을 볼 수 있어요. 화면을 끌어서 살펴봐요.
- 밤에는 동남쪽 하늘에 고리 달린 별 「몽글성」이 떠요. 망원경 한가운데에 맞추면 찾은 거예요.
- 맑은 밤에 망원경으로 보면 별이 훨씬 많이 보이고 색색 성운과 은하도 보여요.
- 하늘에 몽글 마을 별자리 여덟 개가 숨어 있어요 (별사탕·토끼·푸딩·고양이·곰돌이·등대·버섯·사자). 망원경 한가운데에 맞추면 이름이 떠요.
- 돗자리에 누우면 별자리가 어디쯤 있는지 희미하게 보여요.
- 돗자리에 누우면 하늘만 보여요. 유성우가 내릴 때 가장 잘 보이는 자리예요.
- 벤치에 앉으면 마을이 내려다보여요.
- 낮이라 별이 안 보이면 밤인 채널로 가 보세요 (채널마다 1시간씩 달라요).
- 언덕에도 별사탕이 2개 있어요 (중턱 바위 위, 천문대 뒤).
- 별지기 두두(두더지)가 망원경 옆에서 별 이야기를 해 줘요.

## 너른 들판

마을·숲·오두막·언덕·해변은 큰 원 하나 안에 있고, 그 사이 들판과 바닷가는 어디든 걸어서 건너갈 수 있어요.
길을 따라가지 않아도 숲에서 언덕으로, 오두막에서 해변으로 바로 갈 수 있어요. 원 바깥은 큰 소나무 숲이 둘러싸고 있어요.

- 꽃동산 (북동쪽): 꽃나무에 둘러싸인 돗자리에 앉아 쉴 수 있어요.
- 연잎 연못 (북서쪽): 연꽃이 떠 있는 연못과 벤치가 있어요.
- 모닥불 야영지 (남동쪽): 텐트 옆 모닥불 둘레 통나무에 앉을 수 있어요. 밤에는 불빛이 주변을 밝혀요.

## 돌아다니는 동물 친구들

- 꼬마 여우 포포: 오두막과 폭포 사이 숲에서 나비채를 들고 나비를 쫓아요. 밤에는 오두막 현관 옆에서 자요.
- 오리 가족: 북쪽 숲 옹달샘에서 엄마 오리를 따라 아기 오리들이 헤엄쳐요.
- 우체부 찍찍이: 마을과 오두막 사이 숲길을 오가며 편지를 배달해요.
- 거북이 할머니: 마을 길을 아주 느릿느릿 산책해요.

- 꽃게 아저씨: 해변 물가를 옆걸음으로 오가요.
- 갈매기 끼룩이: 부두 말뚝 위에서 바다를 지켜봐요.

가까이 가면 멈춰서 말을 걸어요. 동물 친구들은 각자 화면에서 따로 움직여요.

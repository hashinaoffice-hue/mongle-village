# 몽글 마을 (멀티플레이)

채널을 골라 들어가면 같은 채널 사람들과 들판과 숲, 폭포 뒤 동굴, 별빛 언덕, 해변을 함께 산책할 수 있는 3D 맵이에요.
처음 들어올 때 닉네임을 정해요 (비워 두면 랜덤). 닉네임은 그 접속 동안만 쓰고, 새로고침하면 다시 정해요.
같은 채널에 같은 닉네임이 있으면 다른 이름을 골라야 해요. 서버에 저장하는 데이터는 없어요.

## 크리스마스 채널 🎄

12월 한 달 동안(한국 시간) 채널 고르는 화면 맨 위에 「🎄 크리스마스 채널」 버튼이 생겨요. 마을이 하얀 눈에 덮여 있어요.

- 한 채널이 20명으로 꽉 차면 「크리스마스 2」, 「크리스마스 3」…이 저절로 열려요. 버튼을 누르면 자리가 남은 첫 채널로 들어가요.
- 광장의 푸딩 산이 3단 **젤리 크리스마스 트리**가 돼요. 쿠키 계단이 꼭대기까지 이어지고, 금별사탕은 트리 꼭대기 별 아래에 있어요. 해가 지면 전구가 물결·반짝·한꺼번에 차례로 빛나요. 트리 아래엔 선물 더미와 곰돌이가 있어요(선물 더미 위에 올라설 수 있어요).
- 비행선 대신 **산타 썰매**가 트리 위를 8자로 날아요. 맨 앞은 빨간 코 순록 코코, 그 옆에 솜이, 뒤에 방울과 별이예요. 가까이 오면 썰매 방울 소리와 「호 호 호」가 들려요.
- 하늘은 1채널처럼 지금 시각을 따라요. 눈은 날씨 일정에 따라 오다 그치다 하고, 12월 24일 저녁부터 25일 하루 종일은 계속 내려요.
- 비공개 채널을 만들 때 「🎄 크리스마스로」에 체크하면 친구끼리도 크리스마스 마을에서 놀 수 있어요.
- 화면 공유는 공용 채널과 같아요(관리자만).
- **미리보기**: 주소 뒤에 `?xmas=1`을 붙이면 12월이 아니어도 크리스마스 채널에 들어가 볼 수 있어요.
- 기획과 앞으로 더할 것(푸딩 트리, 산타 썰매, 캐롤…)은 `CHRISTMAS_PLAN.md`에 있어요.

## 비공개 채널

친구끼리만 놀고 싶으면 채널 고르는 화면의 「비공개」 줄을 써요.

- **채널 만들기**: 누르고 캐릭터를 고르면 새 채널이 만들어지고 6글자 코드(예: `K7MPQ2`)가 나와요. 코드는 화면 왼쪽 위 이름표와 채팅창에 보여요. 이 코드를 친구에게 알려 주세요.
- **채널 입장**: 친구에게 받은 코드를 넣고 「확인」을 누른 뒤 캐릭터를 고르면 그 채널로 들어가요. 대문자·소문자는 상관없어요.
- 하늘과 날씨는 만들 때 골라 둔 공용 채널과 같아요. 정원은 공용 채널과 같은 20명이에요.
- 아무도 없이 3분이 지나면 채널이 사라져요. 그 전에 「친구 바꾸기」로 잠깐 나갔다 와도 같은 코드로 다시 들어와요.

## 관리자 모드

채팅창(Enter)에 `/` 다음에 관리자 코드 12자리를 붙여 치면(예: `/abcd1234EFGH`) 관리자 모드가 켜져요.
`/`로 시작하는 말은 채팅으로 나가지 않아서 다른 사람에게 보이지 않아요. 접속 한 번에 5번까지 틀릴 수 있어요.

- 관리자는 공용 채널에서도 화면 공유를 할 수 있어요.
- 관리자는 신고를 받아도 쫓겨나지 않아요.
- 관리자 코드는 저장소에 없고, 코드를 알아낼 수 없는 지문(SHA-256 해시)만 `server.js`의 `ADMIN_HASHES`에 있어요. 코드를 더 만들고 싶으면 Render 환경 변수 `ADMIN_CODES`에 쉼표로 넣으면 돼요.
- 관리자 모드는 그 접속 동안만 켜져 있어요. 새로고침하면 다시 쳐야 해요.

## 신고

다른 친구의 캐릭터를 마우스 오른쪽 버튼으로 누르면(휴대폰은 꾹 누르기) 이름과 「신고하기」 버튼이 떠요. 잘못 누르지 않게 두 번 눌러야 신고돼요.

- 한 채널에서 **서로 다른 사람 3명**에게 신고받으면 마을에서 내보내지고, 그 **기기(브라우저)**로는 **2시간** 동안 못 들어와요.
- 같은 기기가 누적으로 **9번** 신고받으면 그 기기는 **영구 차단**돼요.
- 차단은 기기 단위라서, PC방·학교·카페처럼 인터넷 주소(IP)를 같이 쓰는 곳의 다른 사람은 함께 막히지 않아요.
- 신고한 사람은 IP로 세요. 한 사람이 창을 여러 개 열어 혼자 3번을 채울 수 없게요. 그래서 같은 곳(같은 IP)의 여러 명이 신고해도 1번으로 세요.
- 기기 표는 서버가 처음 들어올 때 주는 무작위 번호예요(서명이 있어서 꾸밀 수 없어요). 이름·이메일 같은 개인정보는 없어요.
- 한계: 차단된 사람이 시크릿 창을 쓰거나 브라우저 데이터를 지우면 새 기기로 다시 들어올 수 있어요. 또 말썽을 부리면 다시 신고로 쫓겨나요.
- 신고·차단 기록은 `BAN_FILE`을 정해 두면 파일에 남아요(서명 열쇠는 그 옆 `.key` 파일). 정하지 않으면 메모리에만 있어서, 서버가 잠들거나 재배포될 때 모두 사라져요.

## 실행

`start.bat`을 더블클릭하세요. 처음 한 번은 필요한 파일을 설치해요.
직접 실행하려면:

```
npm install
npm start
```

켜지면 접속 주소가 표시돼요.

- 이 PC: http://localhost:8787
- 같은 와이파이의 다른 기기: http://(표시된 IP):8787

## 인터넷에 배포 (Render)

> 사람이 많이 몰릴 때를 위한 서울 서버(Lightsail + Cloudflare) 이사 안내는 `DEPLOY.md`에 있어요.

1. 이 폴더를 GitHub 저장소에 올려요.
2. [Render](https://render.com)에서 **New → Blueprint**를 누르고 저장소를 고르면 `render.yaml` 설정대로 서버가 만들어져요.
3. 배포가 끝나면 `https://(서비스 이름).onrender.com` 주소로 누구나 접속할 수 있어요.

무료 요금제는 15분 동안 아무도 없으면 잠들어서, 그다음 첫 접속은 30초~1분 정도 걸려요.

## 설정

| 환경 변수 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | 8787 | 서버 포트 |
| `MAX_PER_CHANNEL` | 20 | 채널당 최대 인원 (채널은 10개) |
| `UFO_CHANCE` | 0.1 | 유성우가 내릴 때 생기는 깜짝 이벤트 확률 (0~1) |
| `ADMIN_CODES` | (없음) | 관리자 코드를 더 쓰고 싶을 때 쉼표로 구분해서 넣어요 |
| `MAX_PRIVATE` | 300 | 동시에 열 수 있는 비공개 채널 수 |
| `XMAS` | (날짜대로) | `1`이면 크리스마스 채널을 늘 열고, `0`이면 닫아요. 비워 두면 12월에만 열려요 |
| `MAX_PLAYERS` | 2000 | 서버 전체 동시 접속 상한. 넘으면 「잠시 뒤에 와 주세요」 |
| `MAX_PER_IP` | 10 | 한 IP에서 동시에 열 수 있는 접속 수 |
| `BAN_FILE` | (없음) | 정해 두면 신고·차단 기록을 이 파일에 남겨서 서버를 다시 켜도 이어져요 (기기 표 서명 열쇠는 옆의 `.key` 파일) |
| `DEVICE_SECRET` | (없음) | 기기 표 서명 열쇠를 직접 정할 때. 바뀌면 모든 기기 표가 새로 발급되고 차단도 풀려요 |
| `HOST` | 0.0.0.0 | 서버가 듣는 주소. Cloudflare Tunnel 뒤에서는 `127.0.0.1` |
| `TRUST_PROXY` | Render에서는 켜짐 | `1`이면 프록시가 알려 주는 접속자 IP(`X-Forwarded-For`)를 믿어요. 내 PC에서 켤 땐 꺼 두세요 |

## 하늘과 시간

하늘은 지금 시각(한국 위도·경도 기준)에 맞춰 새벽·아침·낮·노을·밤으로 바뀌어요.
채널마다 1시간씩 늦어요. 1채널이 지금 시각이고, 2채널은 1시간 전, 10채널은 9시간 전이에요.
채널을 고를 때 버튼의 작은 동그라미로 그 채널이 낮인지 밤인지 볼 수 있어요.
다른 시간대를 미리 보려면 주소 뒤에 붙이세요.

- `?t=19.5` : 오늘 19시 30분으로 고정 (1채널 기준, 다른 채널은 여기서 1시간씩 늦어요)
- `?t=5&speed=600` : 새벽 5시부터 600배 빠르게 흐름

## 날씨

채널마다 따로 비나 눈이 와요. 한번 시작하면 4시간 이어져요.

- 비: 가랑비로 시작해 점점 세차게 내리고, 가장 세찰 때는 천둥번개가 쳐요.
- 눈: 오래 내릴수록 마을 곳곳에 쌓이고, 끝나 갈 무렵 눈이 그치면서 녹아요. 많이 쌓이면 걸을 때 사박사박 소리가 나요.
- 날씨에 따라 동물 친구들이 하는 말도 달라져요.
- 채널 고르는 화면에서 버튼의 '비', '천둥', '눈' 표시로 그 채널 날씨를 볼 수 있어요.

날씨는 시각과 채널 번호로만 정해져서(6시간마다 절반 조금 넘는 확률로 한 번) 서버에 저장하는 것이 없고, 같은 채널 사람은 같은 날씨를 봐요.
미리 보려면 주소 뒤에 붙이세요: `?w=rain&wp=0.7` (종류 `rain`/`snow`, 4시간 중 얼마나 지났는지 0~1)

## 몽글 해변과 등대

마을 남쪽 문을 나서서 잔디 언덕길을 내려가면 모래사장과 바다가 나와요.

- 바다는 무릎 깊이까지 걸어 들어갈 수 있어요. 걸으면 첨벙첨벙 소리가 나요.
- 파라솔 아래 의자에 앉아 바다를 볼 수 있어요.
- 나무 부두를 따라가면 등대 섬이 나와요. 등대 문 앞에서 전망대로 올라갈 수 있어요.
- 밤이 되거나 비가 세차게 오면 등대 불빛이 빙글빙글 돌아요.
- 해변에도 별사탕이 3개 숨어 있어요 (모래성, 부두, 등대 전망대).

## 반딧불 동굴

오두막 숲의 무지개 폭포, 물줄기 바로 뒤 절벽에 숨은 입구가 있어요. 연못 가장자리를 돌아 물줄기 뒤로 가면 들어갈 수 있어요.

- 동굴 안은 바깥 시간과 날씨에 상관없이 늘 어스름하고, 빛나는 버섯과 수정, 반딧불이 길을 밝혀요.
- 빛나는 연못은 얕아서 걸어 들어갈 수 있어요. 가운데 작은 섬이 있어요.
- 천장을 올려다보면 반딧불이 별처럼 박혀 있어요.
- 서쪽 굴 끝 수정 방에는 폭신한 분홍 버섯이 있어요. 밟으면 높이 튀어 올라 수정 선반에 닿을 수 있어요.
- 연못가 바위에 앉아 쉴 수 있어요.
- 동굴에도 별사탕이 2개 있어요 (연못 섬, 수정 선반).
- 꼬마 박쥐 초롱이 종유석에 거꾸로 매달려 있어요.

## 별빛 언덕과 천문대

마을 광장에서 동쪽 이정표를 따라 오솔길을 오르면 언덕 꼭대기에 천문대가 있어요.

- 망원경 앞 의자에 앉으면 망원경으로 하늘을 볼 수 있어요. 화면을 끌어서 살펴봐요.
- 밤에는 동남쪽 하늘에 고리 달린 별 「몽글성」이 떠요. 망원경 한가운데에 맞추면 찾은 거예요.
- 맑은 밤에 망원경으로 보면 별이 훨씬 많이 보이고 색색 성운과 은하도 보여요.
- 하늘에 몽글 마을 별자리 여덟 개가 숨어 있어요 (별사탕·토끼·푸딩·고양이·곰돌이·등대·버섯·사자). 망원경 한가운데에 맞추면 이름이 떠요.
- 돗자리에 누우면 별자리가 어디쯤 있는지 희미하게 보여요.
- 돗자리에 누우면 하늘만 보여요. 유성우가 내릴 때 가장 잘 보이는 자리예요.
- 벤치에 앉으면 마을이 내려다보여요.
- 낮이라 별이 안 보이면 밤인 채널로 가 보세요 (채널마다 1시간씩 달라요).
- 언덕에도 별사탕이 2개 있어요 (중턱 바위 위, 천문대 뒤).
- 별지기 두두(두더지)가 망원경 옆에서 별 이야기를 해 줘요.

## 너른 들판

마을·숲·오두막·언덕·해변은 큰 원 하나 안에 있고, 그 사이 들판과 바닷가는 어디든 걸어서 건너갈 수 있어요.
길을 따라가지 않아도 숲에서 언덕으로, 오두막에서 해변으로 바로 갈 수 있어요. 원 바깥은 큰 소나무 숲이 둘러싸고 있어요.

- 꽃동산 (북동쪽): 꽃나무에 둘러싸인 돗자리에 앉아 쉴 수 있어요.
- 연잎 연못 (북서쪽): 연꽃이 떠 있는 연못과 벤치가 있어요.
- 모닥불 야영지 (남동쪽): 텐트 옆 모닥불 둘레 통나무에 앉을 수 있어요. 밤에는 불빛이 주변을 밝혀요.

## 화면 공유 (빔 프로젝터)

위쪽 「화면 공유」 버튼을 누르고 공유할 화면이나 탭을 고르면, 내 앞 허공에 홀로그램 화면이 떠요. 같은 채널 사람들이 모여서 같이 볼 수 있어요.

- 화면 공유는 **비공개 채널**에서만 할 수 있어요. 공용 채널에서는 잠겨 있고, 관리자만 띄울 수 있어요. 남이 띄운 화면은 어디서든 볼 수 있어요.
- 채널마다 한 번에 한 명만 띄울 수 있어요. 버튼을 다시 누르거나 브라우저의 「공유 중지」를 누르면 꺼져요.
- 띄운 사람은 위쪽 「크기 －/＋」(또는 `[` `]` 키)로 화면을 60%~400%까지 키우거나 줄일 수 있어요. 모두에게 같은 크기로 보여요.
- 소리까지 보내려면 화면을 고를 때 「탭 오디오 공유」(또는 시스템 오디오 공유)를 켜세요. 소리는 화면에 가까울수록 크게 들려요.
- 영상과 소리는 서버를 거치지 않고 사람들끼리 직접 주고받아요(WebRTC). 서버에 저장되는 것은 없어요.
- 화면을 띄우려면 PC 브라우저와 https 주소(또는 localhost)가 필요해요. 휴대폰은 띄울 수는 없고 볼 수만 있어요.
- 회사·학교처럼 막힌 네트워크에서는 연결이 안 돼서 화면이 파란 대기 화면에 머물 수 있어요 (중계 서버(TURN)는 두지 않았어요).
- 보는 사람이 많을수록 띄운 사람의 인터넷 올리기 속도를 많이 써요.

## 비행선 전광판

커다란 비행선이 몽글 마을 광장 위를 2분 30초에 한 바퀴씩 늘 돌아요. 양옆에 전광판이 달려 있고, 운영자가 정해 둔 글·그림·영상이 차례로 나와요.
모든 사람이 서버 시계에 맞춰 같은 위치의 비행선과 같은 화면을 봐요. 지도에도 비행선이 표시돼요.

### 전광판 내용 바꾸기 (운영자)

크리스마스 채널에서는 비행선 대신 산타 썰매가 날고, 썰매 뒤 현수막에 짧은 글(24자까지)이 나와요. `playlist.json`에 `"banner": "메리 크리스마스!"`처럼 넣으면 바뀌어요. 없으면 「메리 몽글 크리스마스!」예요.


`public/airship` 폴더에 그림·영상 파일을 넣고, `public/airship/playlist.json`의 `items`에 나올 순서대로 적어요.

```json
{
  "items": [
    { "type": "text", "text": "몽글 마을에\n어서 와요!", "sub": "작은 글씨 한 줄", "bg": "#f6a9c0", "color": "#4b3a35", "seconds": 12 },
    { "type": "image", "src": "poster.png", "seconds": 10 },
    { "type": "video", "src": "clip.mp4", "seconds": 30 }
  ]
}
```

- `type`: `text`(글), `image`(그림: png·jpg·gif·webp·svg), `video`(영상: mp4·webm)
- `seconds`: 몇 초 동안 보여 줄지. 영상은 이 시간 동안 반복해서 나와요 (없으면 글·그림 10초, 영상 30초)
- `text`의 `\n`은 줄바꿈이에요 (세 줄까지). `bg`는 배경색, `color`는 글자색이에요.
- `src`는 `public/airship` 안의 파일 이름이에요. 다른 사이트 주소(https://…)도 되지만, 그 사이트가 다른 곳에서 가져다 쓰는 걸 허락(CORS)해야 나와요.
- 전광판은 2:1 비율이에요. 다른 비율은 남는 곳이 어두운 색으로 채워져요.
- 영상 소리는 나오지 않아요.
- 고친 뒤 GitHub에 올리면 Render가 다시 배포하고, 접속해 있는 사람들에게도 3분 안에 바뀐 내용이 나와요.
- 영상 파일은 저장소를 무겁게 하니 짧고 작게(수십 MB 이하) 만들어 주세요.

## 돌아다니는 동물 친구들

- 꼬마 여우 포포: 오두막과 폭포 사이 숲에서 나비채를 들고 나비를 쫓아요. 밤에는 오두막 현관 옆에서 자요.
- 오리 가족: 북쪽 숲 옹달샘에서 엄마 오리를 따라 아기 오리들이 헤엄쳐요.

- 거북이 할머니: 마을 길을 아주 느릿느릿 산책해요.

- 꽃게 아저씨: 해변 물가를 옆걸음으로 오가요.
- 갈매기 끼룩이: 부두 말뚝 위에서 바다를 지켜봐요.

가까이 가면 멈춰서 말을 걸어요. 동물 친구들은 각자 화면에서 따로 움직여요.

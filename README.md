# 몽글 마을 (멀티플레이)

채널을 골라 들어가면 같은 채널 사람들과 들판과 숲을 함께 산책할 수 있는 3D 맵이에요.
처음 들어올 때 닉네임을 정해요 (비워 두면 랜덤). 닉네임은 그 접속 동안만 쓰고, 새로고침하면 다시 정해요.
같은 채널에 같은 닉네임이 있으면 다른 이름을 골라야 해요. 서버에 저장하는 데이터는 없어요.

## 실행

`start.bat`을 더블클릭하세요. 처음 한 번은 필요한 파일을 설치해요.
직접 실행하려면:

```
npm install
npm start
```

켜지면 접속 주소가 표시돼요.

- 이 PC: http://localhost:8787
- 같은 와이파이의 다른 기기: http://(표시된 IP):8787

## 인터넷에 배포 (Render)

1. 이 폴더를 GitHub 저장소에 올려요.
2. [Render](https://render.com)에서 **New → Blueprint**를 누르고 저장소를 고르면 `render.yaml` 설정대로 서버가 만들어져요.
3. 배포가 끝나면 `https://(서비스 이름).onrender.com` 주소로 누구나 접속할 수 있어요.

무료 요금제는 15분 동안 아무도 없으면 잠들어서, 그다음 첫 접속은 30초~1분 정도 걸려요.

## 설정

| 환경 변수 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | 8787 | 서버 포트 |
| `MAX_PER_CHANNEL` | 20 | 채널당 최대 인원 (채널은 10개) |

## 하늘과 시간

하늘은 지금 시각(한국 위도·경도 기준)에 맞춰 새벽·아침·낮·노을·밤으로 바뀌어요.
다른 시간대를 미리 보려면 주소 뒤에 붙이세요.

- `?t=19.5` : 오늘 19시 30분으로 고정
- `?t=5&speed=600` : 새벽 5시부터 600배 빠르게 흐름

## 조작

WASD 이동 · Shift 달리기 · Space 점프 · E 인사 · 1~4 한마디 보내기 · 마우스 드래그 시점 회전
휴대폰은 조이스틱과 화면 버튼으로 움직여요.
